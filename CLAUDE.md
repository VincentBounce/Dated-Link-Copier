# Dated Link Copier

Chrome MV3 extension: one click copies a dated reference line for the current page. Everything is in `background.js`: on click it injects self-contained functions with `chrome.scripting.executeScript` (permissions: scripting, activeTab, clipboardWrite, declarativeContent; no host permissions).

## Output formats (`?` when the date is missing on YouTube / Google Play / Reddit / Hacker News / PubMed / Amazon / ScienceDirect Topics / Sony)

- YouTube video: `YYYY-MM-DD @Channel1 @Channel2 - Title https://youtu.be/ID`. Data comes from the player (`#movie_player.getPlayerResponse()`, MAIN world), checked against the video ID in the URL; collaborators come from the owner block's "Collaborators" dialog data. In channels and title, ` - ` becomes `, ` and `\ / : * ? " > < |` become `＼／：＊？＂＞＜｜`.
- Google Play app: `Android YYYY-MM-DD https://play.google.com/store/apps/details?id=…`. Release date = timestamp at `app[10][1][0]` of the AF_initDataCallback block whose `[1][2][77][0]` is the app id (key `ds:5` when signed out, another key when signed in). Read from the loaded page first (instant); only when it has none (some regions get no date for some apps, or stale page after in-page navigation) fetch the app page for regions US, then FR, GB, CH (~1 s each).
- Reddit post: `YYYY-MM-DD https://www.reddit.com/r/<sub>/comments/<id>/<slug>/`. Date = `created-timestamp` of `shreddit-post[id="t3_<id>"]` (new Reddit) or `data-timestamp` of `.thing[data-fullname="t3_<id>"]` (old Reddit), else JSON-LD `datePublished`, shown as the local date like Reddit does. Comment permalinks give the post link. reddit.com blocks curl with a bot check; test in a real browser.
- X (Twitter) post (`x.com` / `twitter.com`, `/<user>/status/<id>`): `YYYY-MM-DD https://x.com/<user>/status/<id>`, computed in the service worker without page access: snowflake ID, `(id >> 22) + 1288834974657` ms (BigInt), shown as the local date; `?` for pre-November-2010 IDs (< 1e13).
- LinkedIn post (`/posts/…-share-ID-…`, `…-activity-ID-…`, `/feed/update/urn:li:activity:ID`): `YYYY-MM-DD https://www.linkedin.com<path without query>`, computed without page access: the 19-digit activity/share/ugcPost ID >> 22 = creation time in ms (BigInt), local date. Checked against the public page's JSON-LD `datePublished`. Pulse articles fall through to the generic reader.
- Amazon product (`www.amazon.{com,ca,co.uk,fr,de,es,it}`, `/dp/<ASIN>` or `/gp/product/<ASIN>`): `YYYY-MM-DD <canonical link with the product name>/` (no query). Date = "Date First Available" row of the product details (`#prodDetails tr`, `#detailBullets_feature_div li`…), labels and month names in English, French, German, Spanish, Italian; many products have no such row, then the oldest `[data-hook="review-date"]` shown on the page ("Reviewed in the United States on February 9, 2026"), then `?`. amazon.com product pages can be fetched with curl and a browser user agent.
- Hacker News item (`news.ycombinator.com/item?id=…`): `YYYY-MM-DD <story title> https://news.ycombinator.com/item?id=<id>`. No date metadata: the UTC time is the `title` of `.fatitem .age` ("2026-10-10T00:37:07", possibly followed by a Unix time), shown as the local date. Title from `.fatitem .titleline > a` through `titleIfNotInLink`; comments have none.
- PubMed (`pubmed.ncbi.nlm.nih.gov/<PMID>/`): `YYYY-MM-DD <title> https://pubmed.ncbi.nlm.nih.gov/<PMID>/`. No date metadata: "Epub 2020 Dec 10." in the first `.secondary-date`, else the issue date before ";" in `.article-citation .cit`; missing day or month become `xx`. Title = `citation_title` without the final period, through `titleIfNotInLink`. PubMed shows a reCAPTCHA to automated browsers: check data with the NCBI E-utilities (`eutils.ncbi.nlm.nih.gov/entrez/eutils/esummary.fcgi?db=pubmed&id=<PMID>&retmode=json`) and the page layout through the Wayback Machine.
- ScienceDirect Topics (`www.sciencedirect.com/topics/…`): `YYYY-xx-xx <link>`, year-only date (the user's format) from the page text "AI generated definition based on: <book>, 2022", else the oldest "From: <book>, YYYY" excerpt. sciencedirect.com blocks both curl and the built-in browser; the parsing is text based for that reason.
- Sony news (`www.sony.com` or `www.sony.net`, `/<lang>/SonyInfo/News/…`): `YYYY-MM-DD <URL without index.html>`. Press releases have no date metadata: the date is the text of `p.mod_text.right` ("September 29, 1998", or "1998年9月29日" on Japanese pages), else `time[datetime]` or `article:published_time`. sony.com blocks curl (403); the Wayback Machine (`web.archive.org/web/2025id_/<url>`) gives the raw HTML.
- Any other page: `YYYY-MM-DD <link>` (nothing copied and ✗ when no date is found) from the first complete date (`YYYY-MM-DD`, "2025/06/03" normalized) among `article:published_time`, `itemprop=datePublished`, `name=date`, `citation_online_date`, `dc.date`, `citation_publication_date` (can be the print issue month only, "2026/07") and JSON-LD `datePublished`; canonical link when on the same host, else the URL without tracking parameters.

Title in the line: for the generic reader and Sony, `titleIfNotInLink()` inserts the file-name-safe title (`cleanText`) between date and link when fewer than half of the title's words (4+ letters, accents removed) appear in the link's path, e.g. `2025-06-03 AI tutoring outperforms in-class active learning： an RCT … https://www.nature.com/articles/s41598-025-97652-6`. Title = `citation_title` / `dc.title` / `og:title` / `document.title`, minus a trailing " | <og:site_name>".

## Icon

`icons/icon.svg` (blue rounded square, white calendar, blue chain link) with 16/32/48/128 px PNGs, plus grey 16/32 px copies (`icons/icon-disabled-*.png`) used as the toolbar default. Chrome draws a disabled action grey only on pages the extension can't access, and activeTab makes every web page accessible, so `chrome.action.disable()` alone never greys the icon on http(s) pages. Hence: default icon = grey copy, and a declarativeContent rule (ShowAction + SetIcon with the colored image data) on YouTube videos/Shorts, Google Play app pages, Reddit posts, X and LinkedIn posts (plus Pulse articles), Amazon products, and any other site (`anyHostExcept()` builds a lookahead-free regex, since rules can't exclude hosts).
